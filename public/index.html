Custom WS Tunnel

HTTP-over-WebSocket Reverse Tunnel

Quick Start

Interactive mode (will prompt for server URL & credentials):

curl -fsSL {{INSTALL_URL}} | bash

Or pass credentials directly via environment variables:

TUNNEL_SERVER_URL={{TUNNEL_WSS_URL}} \ TUNNEL_USERNAME=<user> \ TUNNEL_PASSWORD=<pass> \ TARGET_ORIGIN=http://127.0.0.1:8000 \ curl -fsSL {{INSTALL_URL}} | bash

Endpoints

  • GET/__info This page
  • GET/__health Health check
  • GET{{INSTALL_URL}} Install script
  • POST{{CONFIG_URL}} Admin config (HMAC signed)

Environment Variables

  • TUNNEL_SERVER_URL = {{TUNNEL_WSS_URL}}
  • TUNNEL_USERNAME = <your-username>
  • TUNNEL_PASSWORD = <your-password>
  • TARGET_ORIGIN = http://127.0.0.1:<port>
